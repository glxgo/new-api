# 飓星 API 鹈鹕存档接入实施方案

更新：2026-09-23。用户确认本地开发；生产写入和上线仍须单独确认，沿现有蓝绿流程。本文取代本站自测 V6 和迁移前的推测性接入方案。

## 目标

外部网站已对飓星渠道执行鹈鹕测试。本站只读同步、保存、关联和展示，不出题、不调用模型、不重新评分、不控制外部调度。

用户确认当前正确答案为 **21**；历史记录继续保留各自答案与来源判定。不要求 HTML/SVG 2D 动画，遵循外部现有作品。

```text
外部 SQLite 完成记录 → 受限 SSH 只读导出 → 私有原子快照
  → 本站事务存档 → provider_id / model 显式关联 Channel.Id / 模型
  → 按当前分组成员和用户权限引用 → new-api 用户页与后台
```

无需先搭通用内网穿透。本机已成功只读 SSH 到迁移后的服务器；正式运输使用独立受限账号、固定导出命令。生产服务器间网络仍须部署前核验。

## 实际来源契约

已核实镜像为 llm-api-bench:2.15.3-balance-alerts1。白名单读取 pelican_runs、pelican_targets、pelican_config。首次验收快照为8个目标、240条记录，自动执行开启、默认60分钟；均为快照事实，不写死为产品规则。

| 来源事实 | 本站处理 |
| --- | --- |
| provider_id、model_name | 外部目标身份，显式关联本站渠道ID与实际支持的模型 |
| 外部id + 本站source_id | 区分来源与记录；内容SHA256变化另存修订，恢复旧内容重新激活旧修订 |
| created_at | 保留来源测试时间，不以本站同步时间替代 |
| grade、expected_answer、reported_answer | 保留来源原值，不生成本站分数 |
| svg、raw_text、error | 原文私有存档；用户只见安全作品和白名单数据，原响应与错误仅管理员可查 |
| 耗时、TTFT、Token、attempts | 按来源报告；0可能表示未取得计量 |
| prompt_hash | 来源UTF-16 FNV-1a 32位标记，不是密码学完整性证明 |

来源没有全局轮次、历史原题全文、不可变模型ID或本站渠道ID。测试结束后一次插入记录，所以以单个渠道/模型的完整记录为更新单元，图像、答案、判定一起更新。未有新完成记录时保留旧记录及原时间，不能虚构全局同轮完成。

原题仅在记录版本标记与当前配置吻合时附上，并明确按来源配置匹配；不匹配则说明未保存原题。默认提示词提取器只读取已核实格式的grader文本，不执行代码；格式变化时失败并保留旧快照。

## 渠道、模型、分组

- 显式绑定稳定ID，不按名称猜测。外部新增目标自动同步但保持未关联，不能自动绑定未知生产渠道。
- 同渠道在多分组引用相同记录ID，不复制样本、不重复调用。
- 每次请求检查渠道仍存在、分组成员、模型列表、能力关系和用户权限；详情及作品直链同样检查。本站渠道停用不取消真实外部记录的展示资格，前提是来源目标仍启用、关联有效且没有被后台隐藏。
- 业务停用会同时禁用能力行；存档展示允许停用渠道继续引用已有能力关系，不重新启用渠道或改写能力。渠道启用时单独禁用的能力仍不参与展示。能力缺失、模型撤下、移出分组、删除渠道或隐藏仍阻止相应访问。
- 仅由停用渠道提供的已关联模型也进入智商测试的模型目录，不改变正式模型路由。浏览器每30秒刷新，已交付的数据不能远程收回。
- 渠道改名不改身份。分组采用独立UID，沿现有改名事务维护；倍率实时继承，展示别名和描述不改变路由名或价格。
- 主节点目录刷新自动发现本站新分组，已绑定渠道按成员关系自动展示。外部模型改名视为新目标，需要确认映射。
- 来源移除或停用目标后不作为当前公开结果；本站历史证据保留后台。
- 管理接口提供已保存关联的核对报告：当前分组、展示名、倍率、是否可参与精选、不能展示的具体原因。后台和公开接口共用渠道/成员/模型/能力判定；报告不等于承诺入选前三，也不替代用户权限与页面开关。
- 编辑中的表单与已保存报告明确区分。切换渠道清空旧模型；模型须来自所选渠道实际列表，后端仍作独立校验。每30秒刷新目录与报告，未保存草稿保持不变。
- 真实生产核对见 `pelican-channel-audit-2026-09-23.md`。6项由同地址/密钥/模型核验确认；另外kedaya→#9、shuai-gpt020→#36的密钥和模型核验一致，入口等价已由用户确认，当前8项目标身份均已确定。尚未写入生产关联；未来新增未知目标仍保持未关联，不用演示关系替代生产关系。

## 同步与存档

export.py 使用SQLite只读模式、query_only和一致性事务，仅读指定字段，不读providers密钥或环境变量。pull.py 使用严格SSH主机校验、30秒超时、32MiB上限、0600临时文件、fsync和原子改名。

运输工具支持单次和自定义间隔循环，同路径排他锁阻止并行覆盖；失败保留旧快照并继续后续周期。程序内导入仍独立按后台设置运行。生产常驻管理器或定时器须部署时配置，本地有限轮验收不代表生产已启用运输。

应用主节点每30秒检查一次计划，导入间隔可自定义1–1440分钟；slave候选不导入且管理写入只读。独立运输任务按自身周期拉取。后台暂停的是本站导入与公开更新，不停止外部测试或独立拉取任务。

快照全量校验后事务导入，去重、内容修订和旧修订恢复均有明确语义。来源身份变化、损坏、超限、捕获时间倒退、超过24小时的快照或配置冲突会拒绝导入；失败保留既有结果。配置写入采用版本CAS和事件记录。

大文本使用GORM无长度string适配三库。证据内容上限为100000条修订或512MiB原文与题目，触限拒绝新增并报错，不自动删除证据。数据库文件、索引、审计和备份空间另计；运营须监测容量并在触限前确认归档保留策略。

SVG通过鉴权接口作为blob图片展示，不插入页面HTML。附CSP sandbox/nosniff，允许非递归本地use并限制展开规模，拒绝脚本、外链、foreignObject和不支持的主动内容。无法安全预览不改变来源判定，原记录仍供后台核查。

## 用户界面

入口为使用日志和模型状态之间的“智商测试”。Default使用现有Base UI、Classic使用Semi，主题沿本站。桌面最多三图同排，手机单列，历史在下。

每个渠道/模型只用最新完整记录参与精选：先可预览作品，再优先来源答案匹配，再按时间排序，最多三个。不足三个展示实际数量，不复制图片凑样本；不能用旧匹配记录掩盖新未匹配记录。历史按实际时间展示，不虚构成功率或IQ分数。

点击作品、历史色块可查题目、答案、图像和来源调用数据。六章专业解释通过三栏摘要和阅读面板展开，覆盖对象、证据、精选、阅读、追溯和解释边界。

图廊仅原图、宽度贴合卡片且高度随原比例。详情分为原始作品、题目与答案、记录数据；原图支持适应宽度与150%/200%查看，不改作品内容。标准答案与检测数字并列，保留来源判定和原题可追溯性说明。页头显示存档获取时间，具体记录保留测试时间；不能用重复导入旧快照的时间表示来源已有更新。优选规则不包含审美评分。

## 后台

停用渠道的真实记录沿用统一前台表述，不增加“存档样本”等标签；业务启停只在后台核对说明。公开页继续保留真实测试时间、原作与判定，不宣称每次实际请求均由入选渠道处理。

系统设置“智商测试”分为存档设置、来源记录、用户预览：

- 同步启停、自定义间隔、立即同步、显示、隐藏并暂停、仅隐藏；不冒充外部控制按钮。
- 读取本站渠道、模型与分组，关联外部目标；隐藏单目标不关闭业务渠道。
- 分组别名、描述、隐藏、整行上下排序，历史与方法说明开关。
- 展示文案标明页面位置，支持折叠、全部展开/收起、未保存提示、应用和放弃；其他设置保存不应清空草稿。
- 来源记录分页、原文、用量、修订和管理事件；管理员隐藏态预览不会公开页面或触发测试。
- 修改配置沿用Root权限，普通管理员只读；普通用户不能访问来源原文。
