## 本轮合理性修正

### 2026-09-22 动画生成证据与播放链路

- 鹈鹕提示词逐字采用用户原句；移除海边/围巾/橙子/太阳等原题没有提出的约束。六项分别观察主体、自行车、骑乘关系、二维表达、观察到的运动与骑行动作；逻辑与静态规则几何题保留。随机动画扩展仍待补，不能把固定题实现称为全题库完成。
- 新增独立Chromium渲染分支，支持CSS/SMIL/内联JavaScript。固定600×400、每100毫秒一帧，共48帧；后端生成无损APNG、首帧海报及六帧拼图，记录原文哈希/渲染器/浏览器版本/时间点。外部资源与本地文件读取拒绝；主应用和用户页不执行上游HTML。
- 评审调用绑定实际六帧拼图哈希。是否运动与是否骑车分开核验；无像素变化不能给运动项通过，变化也不会自动升分。新套题、渲染器与浏览器版本均进入校准门禁，旧静态报告不能启用动画任务。实际人工校准仍未执行，不存在可用的正式校准报告。
- 初次执行与补评复用同一渲染函数；补评可复用同源、同版本的已存制品，禁止将已有judge回答配到另一张图。原回答不会再次生成，补评只追加修订，不回写原快照。
- 同一路由鉴权保护首帧、动画和评审拼图。路由测试覆盖匿名拒绝、history关闭旧直链拒绝、隐藏后用户动画不可读、后台仍可查、跨run修订拒绝以及DTO地址改写。
- Default用户详情、后台原记录与补评记录复用原生按钮/图片/折叠；Classic用户详情使用Semi按钮。默认静止，明确点击播放/停止，证据展开才加载。Default新增5项六语文案，并把方法介绍改为与实际观察窗口一致；历史浮层显示方法版本。
- 本地生成的移动圆形只作链路样例：预览4197的顶部和原回答均明确标注，不代表模型生成鹈鹕或真实成绩。浏览器已实查APNG画面移动、停止回首帧、六帧对应、390px深浅色、键盘展开；热更新会整页重载，不影响正式构建。
- 验证：定向五包 `-race -vet=off` 通过；本地Chromium/resvg＋HTTP模拟上游＋SQLite完整轮次/中断恢复通过，生成12次保持不变、judge仅3→4。APNG每帧独立解码与像素比较、CRC/帧序/时刻、静态和非法帧回归通过。Node覆盖CSS/SMIL/JS/静态、外网/本地文件/样式资源/iframe拒绝及无限脚本/客户端取消。Default类型、功能ESLint与双前端生产构建通过。
- Dockerfile已补浏览器依赖，Linux无网络非root沙箱、资源限制、启动阶段取消/崩溃回收与字体/镜像校准仍是发布阻断项；详见 `tools/capability-renderer/README.md`。没有生产操作、迁移、提交或推送。

## 2026-09-22 恢复链路验证明细

- SQLite＋真实本地 resvg＋本地 HTTP 模拟上游，先令渲染器离线，再恢复并更换 worker owner。恢复前后被测模型生成次数保持 12，judge 从 3 增至 4，只新增尚未派发的首次评审；后续检查不再增加调用。原结果与先前公开快照逐字比较保持不变。
- 覆盖完整答案持久化后、结果检查点前中断；原文可继续本地逻辑判分。模拟数据库读取故障保持待恢复，不误永久取消；确定缺失证据才阻塞。相同结果重复检查不新增答案副本，修订编号独立于检查次数。
- 评审 outcome_unknown 与 PNG hash 不匹配阻塞自动补评；并发领取只有一个任务、worker 接管拒绝旧 owner、stop/resume 不复活旧任务；恢复调用同样受预算与唯一派发约束。自定义一分钟计划使用剩余窗口，可补首次评审，不因要求固定180秒窗口而永久饥饿；发送后超时依然不自动重发。
- 原生 API 路由测试覆盖匿名/普通用户拒绝、管理员及 root 可读、隐藏后后台仍可读、跨 run 取修订图返回404、no-store/nosniff/CSP。没有用界面隐藏代替服务器鉴权。
- 本轮最终 `go test -race -vet=off ./model ./service ./controller ./router ./pkg/capabilitytest -run 'Test(Capability|Logic|Questions|SVG)' -count=1` 通过。本地 `go build ./...` 通过；Default typecheck、功能 ESLint/Prettier、生产构建通过。沿用既有 Go vet 基线排除，非全仓默认测试通过声明。
- 新增恢复文案共13项已补齐 Default 六语并同步；全功能既有未翻译项仍待处理。浏览器验收使用明确标识的模拟接口，不能替代真实后端界面或收费模型验收；开发热更新日志有自动整页重载记录。
- 没有生产读写、迁移、上传、提交、推送或真实付费调用。新增恢复表与 attempt 图片哈希字段已纳入独立迁移工具，但未执行生产迁移。
